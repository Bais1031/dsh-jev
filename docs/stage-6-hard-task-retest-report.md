## Summary

本次复测先对四个高难候选任务运行 Baseline，再选择出现无效探索的冲突证据和工具恢复任务族，使用未见变体分别运行两次 Baseline、Shadow 和 Advisory。四次筛选和十二次配对运行的关键决策全部正确；Advisory 没有修正 Baseline 错误，也没有减少 step、无关工具调用或重复调用，平均总 token 增加约 4.1%，平均时延增加约 98.0%。准确性非回归通过，准确性提升和效率门禁未通过。

## 结论

高难任务复测没有改变阶段六结论。当前测试证明触发器可以在目标节点提供稳定简报且不降低正确率，但没有证明简报能修正主模型错误或减少无效探索。当前 Advisory 仍是额外 token 和延迟成本，不能宣称提高准确率或节省 token。

下一轮不应继续增加同类配对次数。应先改进任务发现方法：从真实失败 Session 或可复现的主模型错误中提取任务，在不向主模型直接提示恢复路径的前提下冻结评分规则；只有 Baseline 错误能在独立变体中稳定复现时，才重新评估 Advisory。
